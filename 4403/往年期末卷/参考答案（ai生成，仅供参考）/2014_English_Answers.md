# CITS4403 Final Examination 2014: English Answers

Suggested answers for revision, not an official marking guide. Questions are in bold; answers are in plain text.

**Q1. When is it not possible to create a random graph of size n and degree k? [5 marks]**

Taking k to mean the degree of every node in a simple undirected graph, it is impossible if k is not an integer, k<0, k>=n, or nk is odd. A node cannot connect to more than the other n-1 nodes, and the sum of degrees must equal twice the number of edges. Therefore, n and k cannot both be odd. For positive integer n, the conditions 0<=k<n and even nk are sufficient for a k-regular simple graph. Randomising its construction cannot remove these constraints. If k means only an expected degree, the parity condition does not apply.

**Q2. Explain what a random graph is and how to generate one. [5 marks]**

A random graph is a graph generated by a random process. In the Erdos-Renyi G(n,p) model, first create n nodes with no edges. Consider each unordered pair of distinct nodes once. Add an edge independently with probability p. Do not add self-loops or duplicate edges. The expected degree is (n-1)p, and the expected number of edges is n(n-1)p/2. Individual degrees and the total number of edges can differ between runs.

**Q3. Give an algorithm for determining if a graph is connected or not. [5 marks]**

For an undirected graph, start at any node and use breadth-first search to find every node reachable from it. Mark a node when it is first added to the queue. The graph is connected if and only if every node is reached.

```text
is_connected(G):
    if G has no nodes:
        return True  # convention for this algorithm
    start = any node in G
    visited = {start}
    queue = FIFO queue containing start
    while queue is not empty:
        u = queue.remove_front()
        for each neighbour v of u:
            if v is not in visited:
                visited.add(v)
                queue.add_back(v)
    return size(visited) == number_of_nodes(G)
```

The empty-graph case is handled by the stated convention. For a directed graph, this test alone does not establish strong connectivity.

**Q4. What is the order of growth of radix sort? [5 marks]**

For n keys with d digits in base b, radix sort takes O(d(n+b)) time when each digit pass uses a stable counting sort. Each pass processes n keys and b possible digit values, and there are d passes. For a fixed base and a fixed number of digits, this is O(n). If key length grows, d must be included: for example, d is proportional to log_b U for values below U. Radix sort is not unconditionally linear for arbitrarily long keys.

**Q5. Explain how the Hashtable add operation can take constant time on average despite the need to resize the map. [5 marks]**

Use a hash table and enlarge it by a constant factor, such as doubling its capacity, when it gets too full. Most insertions require only a hash calculation and a short search. An occasional resize costs O(n) because existing entries must be rehashed.

However, resizing happens only after many insertions. The total rehashing work over n insertions is proportional to 1+2+4+...+n, which is O(n). Spread across those insertions, the expected amortised cost is O(1) per insertion, assuming a good hash function. A single insertion can still be slow.

**Q6. What was Stanley Milgram's Small World Experiment and what did it show? [5 marks]**

Participants tried to send a letter to a target person by passing it only to someone they knew personally. Each recipient chose an acquaintance thought to be closer to the target. Completed chains were surprisingly short, commonly summarised as about six acquaintance links. The experiment suggested that distant people can be joined by short social paths, the small-world phenomenon. However, many chains were not completed and the sample was limited. It did not prove that every pair of people is separated by exactly six links.

**Q7. Describe two different explanations for the Small World Phenomenon. [5 marks]**

One explanation is the Watts-Strogatz model. Most links join nearby nodes, forming local groups, but a few long-range shortcuts connect those groups. Even a small number of shortcuts can greatly reduce average path length while preserving high clustering.

A second explanation is the Barabasi-Albert model. The network grows, and new nodes preferentially connect to nodes that already have many links. This creates hubs, which provide short routes between many nodes. The basic BA model explains a broad degree distribution, but usually has less clustering than real social networks.

**Q8. Briefly describe Dijkstra's shortest-path algorithm. [5 marks]**

Dijkstra's algorithm finds shortest paths from one source when all edge weights are non-negative. Set the source distance to zero and every other distance to infinity. Keep tentative distances in a priority queue.

Repeatedly remove the unsettled node u with the smallest tentative distance. For each edge u to v of weight w, replace distance[v] by distance[u]+w if this is smaller, and update the queue. Record predecessors if the actual paths are needed. Continue until the queue is empty. Nodes that cannot be reached retain infinite distance.

**Q9. How would you characterise the typical main differences between a computational modelling explanation for a phenomenon compared to a more traditional scientific one? [5 marks]**

A traditional explanation often looks for a small set of equations and an analytical solution. It may simplify the system by treating its components as identical and studying them separately.

A computational explanation specifies components, local rules and interactions, then runs a simulation to see what collective behaviour follows. It can keep differences between agents, spatial structure and randomness. For example, Schelling's model explains segregation through repeated local moves rather than a single equation. These are typical tendencies, not a strict division: traditional science also uses computation, and computational models still need evidence and validation.

**Q10. What is Zipf's law? [5 marks]**

Zipf's law describes a rank-frequency relationship. Rank items from most frequent to least frequent. The frequency of the item at rank r is approximately proportional to 1/r: f(r)=C/r. Thus, the second-ranked item occurs about half as often as the first, and the third about one third as often.

Word frequencies are a common example. A log-log plot of frequency against rank is approximately a straight line with slope -1. This is a statement about rank and frequency, not directly a probability density over word counts.

**Q11. What is a Pareto distribution? [5 marks]**

A Pareto distribution is a heavy-tailed distribution for positive values above a minimum x_min. Its upper-tail probability is P(X>=x)=(x_min/x)^alpha for x>=x_min, where alpha>0. Its density is proportional to x^(-(alpha+1)).

Most values are relatively small, but very large values remain more likely than under an exponential tail. The tail is scale-free: multiplying x by a fixed factor changes the tail probability by a fixed factor. Smaller alpha means a heavier tail. The mean is finite only for alpha>1, and the variance only for alpha>2. The 80/20 rule is an example, not a requirement of every Pareto distribution.

**Q12. Describe at least one major objection to Popper's claim that falsifiability demarcates science from pseudo-science. [5 marks]**

A failed prediction tests more than the main theory. It also depends on auxiliary assumptions, initial conditions and measuring equipment. If the prediction fails, we may not know which part is wrong. Scientists can reasonably check the equipment or revise an assumption rather than immediately reject the theory.

Also, a probabilistic theory usually does not forbid any single outcome, so one unusual observation need not falsify it. These difficulties make falsifiability a useful scientific ideal, but not a complete, automatic boundary between science and pseudoscience.

**Q13. Define one-dimensional Cellular Automata. [5 marks]**

A one-dimensional cellular automaton consists of a row of cells, each with a state from a finite set. Time advances in discrete steps. At each step, every cell's next state is determined by the same local rule, using its old state and the old states of nearby cells. Cells are normally updated simultaneously.

In an elementary binary CA, the inputs are the left, centre and right cells, each either zero or one. There are eight input configurations and 256 possible rules. Specify boundaries for a finite row; stacking successive rows gives a space-time diagram.

**Q14. Explain what is special about Rule 110. [5 marks]**

Rule 110 is an elementary one-dimensional binary CA with only a simple local rule, yet it can produce persistent moving structures and complex interactions. It is a Class 4 example.

More importantly, Rule 110 is computationally universal. With a suitable encoding and initial configuration, it can simulate a universal computing system and therefore perform any computable calculation, given enough space and time. Its importance is that universal computation can arise from very simple rules. This does not mean that every starting pattern carries out a useful computation.

**Q15. Is the Game of Life an example of a complex system? Explain your answer. [5 marks]**

Yes. The Game of Life is a two-dimensional CA whose cells follow simple local rules, yet their interactions can produce persistent, moving and interacting structures. Live cells survive with two or three live neighbours; dead cells become live with exactly three. All cells update together using the eight-cell Moore neighbourhood.

Structures such as oscillators, gliders and glider guns emerge without any rule explicitly naming them. Their collective behaviour is richer than the behaviour of a single cell. Some initial states are simple, but the system is capable of complex behaviour and universal computation.

**Q16. Explain how a Cellular Automaton can produce an object of dimension about 1.56. [5 marks]**

Run an elementary CA such as Rule 18 from one live cell on an otherwise empty row. Place each new generation below the previous one. The resulting space-time pattern has repeated triangular structure and holes on several scales.

Count the live cells M(L) in growing portions of this pattern. If M(L) is approximately proportional to L^D, the slope of log M against log L estimates D. Rule 18 gives a value around 1.56-1.58, depending on the finite sample. The ideal triangular scaling gives log(3)/log(2), about 1.585. This dimension belongs to the space-time pattern, not to one individual row.

**Q17. Characterize a holistic approach to modelling something (as opposed to a reductionist one). [5 marks]**

A holistic model focuses on interactions and collective behaviour, rather than expecting the whole system to be understood by studying one component in isolation. It may deliberately simplify individual components to retain the relationships that matter.

For example, Schelling's model gives residents very simple preferences and movement rules. The main question is how their repeated interactions change the whole neighbourhood. Large segregated regions can appear even though no resident is instructed to create them. A reductionist approach would focus more on detailed explanations of individual behaviour; the two approaches can complement each other.

**Q18. Define Self-organized criticality. [5 marks]**

Self-organized criticality means that a driven system develops and maintains a state near a critical point through its own dynamics, without an experimenter carefully tuning a control parameter to that point.

In a sandpile model, grains are added slowly. Cells that exceed a threshold topple and may trigger neighbouring cells. Small inputs can cause anything from no avalanche to a large one, and grains can leave through the boundary. Slow input, local redistribution and dissipation can produce scale-free-looking activity. Not every system with a phase transition is self-organized critical.

**Q19. What does it mean to say that a 10% fall in the stock market may have no explanation? [5 marks]**

It means there may be no special external event large enough to explain that particular large fall. If a market behaves like a critical system, ordinary small disturbances can trigger cascades of many sizes. A large fall may arise from feedback and interactions within the market, just as one ordinary grain can trigger a large sandpile avalanche.

This does not mean that the fall has no causes or that evidence should be ignored. The explanation may lie in the system's structure and dynamics, rather than in one unusually large piece of news. The critical-system interpretation is a hypothesis, not a diagnosis of every crash.

**Q20. Explain how Schelling's modelling is supposed to show that segregation of neighbourhoods arises without racism. [5 marks]**

Place two types of residents and some empty homes on a grid. Each resident checks the fraction of occupied neighbours of its own type. A resident who falls below a modest satisfaction threshold moves to an empty home. Repeat the process; residents with no occupied neighbours need an explicit convention.

Large same-type regions can form even when residents accept mixed neighbourhoods and nobody aims to segregate the whole city. Each move changes other residents' neighbourhoods, creating feedback. The model shows that mild local preferences can be sufficient for strong segregation. It does not prove that racism is absent from real housing patterns.

**Q21. Explain what has been observed about the repeated prisoner's dilemma. [5 marks]**

Repeated Prisoner's Dilemma tournaments show that a strategy need not exploit every opponent to score well overall. Tit for tat performed well in Axelrod's tournaments: cooperate first, then copy the opponent's previous action.

Successful strategies tended to be nice, retaliating, forgiving and non-envious. They could maintain mutual cooperation, respond to exploitation, and return to cooperation when the opponent did. In evolving populations, cooperation and defection can rise and fall as the population changes. These observations support reciprocal cooperation, but do not establish TFT as a universal winner against every possible set of opponents.

**Q22. Discuss the claim that Emergence is just ignorance. [5 marks]**

The claim has some force: we may call a pattern emergent simply because we do not yet understand how it follows from lower-level rules. Better knowledge could explain some apparently mysterious behaviour.

However, emergence can also describe a real distinction between levels of organisation. A traffic jam is a collective pattern created by interacting drivers, not a property of one driver. Even when all local rules are known, predicting their combined result may require running the simulation rather than using a short formula.

Therefore, emergence should prompt a search for mechanisms, not replace one. It is neither automatically ignorance nor proof of something beyond physical rules.

**Q23. Briefly review a chapter of a popular non-fiction book that you have read recently covering a topic related to complexity science. [10 marks]**

Sample review: "The Butterfly Effect", in James Gleick's Chaos: Making a New Science.

The chapter introduces Edward Lorenz's work on weather models and sensitivity to initial conditions. A small difference in the starting state can grow into a large difference in the later result. The central lesson is that deterministic rules do not guarantee reliable long-term prediction.

This connects to the course distinction between deterministic and predictable systems. It also explains why a simulation needs carefully specified initial conditions and why repeated or ensemble runs can be more informative than one forecast.

The chapter's strength is its accessible account of how a surprising computational result changed scientific thinking. Its limitation is that a vivid story is not a full mathematical treatment. Sensitivity alone should not be used as a complete definition of every kind of complexity. Overall, the chapter gives a clear entry point into chaos while leaving the formal analysis to further study.

This is an example review; use a chapter you have actually read when answering a personal-reading question.
